## Unboxed Heroes — Recommended by Zone

### The Backyard (Zone 0)
- **Vegetation:** Common trees, bushes, grass patches, stumps, vines
- **Rocks:** Small/medium stone and dirt variants for scatter
- **Skatepark:** Full set for the ramp/grind area (76 pieces)

- **Vegetation:** Common trees (seasonal variants), bushes for yard scatter

- **Industrial (Scaffold):** Suggests repair/construction abandoned mid-job

## Notes

**URP compatibility:** All Atlased prefabs use the shared atlas material. If materials appear pink in URP, reassign using the materials in `Polyworks/Prefabs/MaterialsOnly/` — these are pre-configured URP variants.

**Naming convention:** All prefabs follow `Category_Description_Variant_01` pattern. Strip `_Atlased` suffix from filenames when referencing in code.

**GPU Instancing:** Enable on the shared atlas material — all prefabs sharing the same atlas draw in one call per batch. Critical for rock/vegetation scatter (dozens of instances).

**Static batching:** Mark all non-moving ENV prefabs as Static in the Inspector. Combine with GPU instancing for maximum draw call savings.

**Triangle budgets (estimated):** Props: 100–400 triangles. Rocks: 50–200 triangles. Vegetation: 200–800 triangles. Buildings (modular pieces): 100–500 triangles per piece.

## The Concept

*Unboxed Heroes* is a mobile action game being built in public — from the first line of code to the App Store — by two people with 20+ years in the IT industry and zero prior game development experience.

The game itself started as a conversation. Not a pitch deck, not a business plan — a conversation between two engineers about an idea Parnez had in Junior High. They tried to build it before. The technology wasn't there. Now it is.

The pipeline they have assembled to build it is something new: Claude writes the code and architects the systems. Claude also writes the prompts used in Meshy to generate the 3D models — AI tools being orchestrated by AI, with a human reviewing every step. They built a custom Blender MCP server with 200+ tools to automate the asset pipeline from model generation through to Unity import. Weave handles storyboard and video production. ElevenLabs provides voice services for characters, narration, and in-game audio. Multiple Claude Code skills and agents enforce quality standards on every asset that enters the game. None of this was off-the-shelf. They built the pipeline.

The game gets built live on Twitch, with the audience watching every design decision, voting on what gets built next, and submitting ideas that actually ship.

This is not a tutorial. It is a build log — with real blockers, real breakthroughs, and a real game at the end.

They built a custom Blender server with 200+ automation tools. They built Claude Code agents that enforce asset quality standards on every model that enters the game. They built the thing, then they stream building the game on top of it.

What viewers see on stream is not every line of code from scratch. The underlying pipeline and tooling were built off-stream. What the audience watches is the game being built on top of that foundation: design decisions, new characters, new systems, new features — in real time, shaped by the community. That distinction matters. The show is about the creative and design layer, not the infrastructure. And that is exactly the layer that is most interesting to watch.

The audience is not watching people who already knew how to do this. They are watching two engineers who tried to build this game before — when the technology was not ready — pick it back up and build it now. That story has an arc. It has something to land on.

## The Community Mechanic

The Unboxed Heroes audience does not just watch — they co-create the game:

1. **Submit** — Anyone can submit a feature request, weapon idea, character concept, or story beat via Discord or the website between episodes.
2. **Vote** — At the top of each live stream, the most-upvoted ideas go to a real-time audience vote.
3. **See it built** — The winning idea gets designed and implemented that episode, on stream, start to finish.

This creates a feedback loop no other gamedev show offers: the audience watches their idea go from suggestion to playable feature in real time. That retention mechanic compounds — viewers come back every week to see if their idea won.

## Partnership Opportunities

### Title Sponsor
One partner is the official tool that makes the show possible. Every episode opens with *"Unboxed Heroes: Build In Public, powered by [Partner]."*

Includes: episode intro mention every week, logo on the website homepage and all episode thumbnails, inclusion in every show description across all platforms, and a dedicated quarterly episode built around the partner's product.

### Presenting Tool Partner
Your tool gets a dedicated *"How We Build With [Tool]"* segment in every episode where it is used — authentic, unscripted, showing real problems being solved. No ad read. Just the work.

Includes: episode intro callout, social post on stream day tagging the partner, website tools page listing, and a featured episode each quarter.

### Community Partner
Co-marketing partnership. We promote your tool to our audience; you promote the show to yours.

Includes: episode outro mention, Discord server resources section, website footer listing, and mutual social amplification on key episodes.

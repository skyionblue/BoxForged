# Achievement Descriptions

*Named and described as if the Kid wrote them herself.*

---

**"First Step"**
*Entered the Cul-de-Sac. Didn't go back.*

**"Perfect Form"**
*Performed a clean parry followed immediately by a counter. On the first try.*

**"Untouchable"**
*Cleared a full room without taking a single hit. Kid already knew this was possible.*

**"The Long Way"**
*Found a hidden path through a zone that most players never see. The box knew.*

**"Spinning Stopped"**
*Defeated SpinCycle. Things that spin eventually stop.*

**"Heavy Hands"**
*Dealt 500 damage in a single room. Some things only need to happen once.*

**"Loaded"**
*Filled every weapon slot simultaneously. Kid stood very still for a moment, then kept going.*

**"Not the First"**
*Found a note left by someone who came before. Read the whole thing.*

**"Reclaimed"**
*Triggered an Imagination Restore. Watched the color come back. Didn't look away.*

**"Already Knew"**
*Completed the game. Kid never doubted the outcome. Not once.*

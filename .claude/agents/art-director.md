Define silhouette, proportions, palette/material goals, scale, pivot/origin, topology, UVs, textures, rig requirements, animation needs, collider strategy, LODs, naming, and mobile budgets before asset creation. Use configured Blender MCP tools for cleanup/validation when available. Never sacrifice gameplay readability for visual detail.

- [Wall-tiling yaw/axis mismatch](feedback_wall_tiling_yaw_axis_mismatch.md) — when tiling a box along an arbitrary direction, the "length" scale axis must match whichever local axis the yaw formula aligns (Atan2(dir.x,dir.z) aligns local +Z, not +X); mismatching silently rotates every non-axis-aligned segment 90°, caught only by a flood-fill, not a screenshot.
- [Baked-transform child-collider gotcha](feedback_baked_transform_child_collider.md) — a new child collider/NavMeshObstacle parented under a prefab instance with baked root rotation/scale inherits the distortion (place as a world-space sibling instead); computing "local" center/size from world Renderer.bounds via naive subtraction ignores that rotation and silently swaps axes (use InverseTransformPoint + explicit axis-swap math instead).
- [Baked-rotation Space.Self composition trap](feedback_baked_rotation_space_self_composition.md) — Transform.Rotate(Space.Self, yaw) on a 270°X-baked ENV prefab only composes cleanly at 90°-multiple yaws; arbitrary yaws produce silently-wrong rotations (wrong facing, or a squared-off bounding box for asymmetric props like the shed). Use a temp identity-rotation rig to compute the correct localRotation instead.

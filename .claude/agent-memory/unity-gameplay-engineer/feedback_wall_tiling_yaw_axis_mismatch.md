Discovered 2026-09-01 building the `Backyard_Dojo` stockade perimeter (see [[project_backyard_dojo_build]]). A `buildWallRun(a, b)` helper computed `yaw = Atan2(dir.x, dir.z) * Rad2Deg` (the standard Unity "look rotation" convention: this yaw, applied via `Quaternion.Euler(0, yaw, 0)`, aligns the object's **local +Z** with `dir`) but assigned the wall's length to **local X** and thickness to **local Z** (`localScale = (segLen, height, thickness)`). Every wall segment running purely along world Z (`dir = (0,0,1)`, `yaw = 0`) came out looking correct by coincidence (at yaw 0, local axes equal world axes, so the mismatch doesn't manifest) — but every rotated segment (a diagonal jog, a chokepoint return running along X, all 14 sides of a 16-gon ring) ended up thin-side-on to its intended direction: a wall meant to seal an 8m gap became a ~0.3m sliver perpendicular to it, leaving a full physical bypass.

**This was caught by a physics-based flood-fill run deliberately early (before trusting the build), not by visual inspection** — a top-down or angled screenshot of a wall segment that's merely thin, rather than obviously wrong, reads as "a wall" at a glance (see [[feedback_baked_transform_compose_rotation]] for the same "plausible screenshot, wrong geometry" trap in a different context). The flood-fill's config-B result (gates closed, stockade on) reaching the full level instead of stopping at zone 0 was the actual tell.

**Fix / rule: length must go on whichever local axis the yaw formula's convention aligns to `dir`.** For `yaw = Atan2(dir.x, dir.z)` (aligns local +Z with `dir`), scale must be `(thickness, height, length)` — length on local **Z**. If instead aligning local +X is wanted, the formula must change to `yaw = Atan2(dir.z, dir.x)` (or equivalently subtract 90°) and scale becomes `(length, height, thickness)`. Pick one convention and verify it with a single non-axis-aligned test segment (e.g. a 45° diagonal) checked via `Renderer.bounds`/`Collider.bounds` in world space before tiling the whole run — a bounds check on a diagonal segment immediately reveals an axis swap that an axis-aligned segment cannot.
